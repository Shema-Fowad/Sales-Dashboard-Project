# Sales Dashboard Project

### Overview
This project analyzes company sales data to uncover key business insights such as top-performing regions, profit trends, and product performance.  
It combines **SQL for data analysis** and **Power BI for dashboard visualization** to present actionable findings for data-driven decision making.

---

### Tools & Technologies
- **SQL (PostgreSQL)** — for data exploration and KPI calculation  
- **Power BI** — for interactive dashboards and visualization  
- **Excel** — for basic data cleaning and formatting  
- **GitHub** — for project documentation and version control

### Business Questions Answered Using SQL
Below are some key analytical questions explored in this project:

1. What is the **total sales, profit, and quantity sold**?  
2. Which **region** generated the highest **revenue**?  
3. Which **states** contribute most to **profit**?  
4. Which **customer segment** drives the most sales?  
5. What are the **top 10 products** by total revenue?  
6. How does **monthly sales** trend over time?  
7. Which **category** has the highest **profit margin**?  
8. What is the **impact of shipping mode** on profitability?  
9. Which **products are loss-making** and need review?
